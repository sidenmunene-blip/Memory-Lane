# Memory Lane

**Author:** Dennis Munene

A photography website for memorable moments, favorite frames, and cars on the open road. Browse the galleries and explore each photograph through its caption.

**Live site:** [Memory Lane on GitHub Pages](https://sidenmunene-blip.github.io/Memory-Lane/)

## Pages

- `index.html` — the landing page, with links to the galleries.
- `Favorites.html` — a featured photograph and a grid of favorite frames.
- `cars.html` — a two-column car photography gallery.
- `contacts.html` — a contact form with links back to the other pages.

## Design and styles

The site uses three CSS files to style its four pages:

- `style.css` gives the landing and contact pages a centered layout on a near-black background. It uses light text, a sky-blue heading and navigation links, a styled contact form, flexible buttons with a hover color change, and a footer anchored at the bottom of the page.
- `favorites.css` gives the favorites page a dark palette. It styles a spacious centered heading, serif title and captions, a large featured image, and a two-column photo grid. Images keep their crop within rounded frames. On screens 650 pixels wide or narrower, the gallery becomes one column and the captions stack vertically. Smooth scrolling is enabled.
- `style2.css` gives the car page a black background with a subtle cyan grid and radial glow. Content is arranged in a two-column CSS grid, with cyan headings and links, italic captions, rounded images, and a footer spanning the page width. The car gallery stylesheet does not define a small-screen layout rule.

## Built with

Static HTML and CSS. No installation or build step is required.

## View the site

### Setup

1. Clone the repository from GitHub:

   ```bash
   git clone https://github.com/sidenmunene-blip/Memory-Lane.git
   ```

2. Open the `Memory-Lane` folder.
3. Open `index.html` in a web browser.

No dependencies, installation, or build step are required. An internet connection is needed to load the externally hosted photographs.

## Photos

All photographs are hosted on external websites and load from those sources. An internet connection is required to view them.
